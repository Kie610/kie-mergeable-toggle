# Mergeable Toggle

VRChat アバター用の NDMF プラグイン。

## 何をするもの

手書きアニメーターレイヤーで `GameObject` のオンオフをしているメッシュトグルを、
ビルド時に **MA Mesh Cutter (NaNimation)** へ機械的に変換する。

AAO (Avatar Optimizer) の自動メッシュ統合は「アクティブ状態のアニメーション」で
メッシュをグルーピングするため、トグルが違うメッシュ同士は統合されない。
本ツールで変換するとメッシュ側は常時アクティブになり(表示切替は NaNimation の
ボーンスケールが担う)、**トグル挙動を保ったまま AAO がメッシュを統合できる**。

## 使い方

1. アバタールートに `Kie/Mergeable Toggle` コンポーネントを追加
2. 検出されたトグル一覧から変換したいものを選ぶ(クリーンな候補は初期状態でオン)
3. そのままビルドするだけ。MA → AAO の順で処理され、統合まで自動で行われる

「要注意」と表示される候補は、メッシュ以外のコンポーネント
(MeshRenderer・ParticleSystem・PhysBone など)がトグル配下にあり、
変換すると常時アクティブになる。挙動を確認のうえ手動でオンにすること。

## 仕組み

1. アニメーターの `m_IsActive` カーブを検出し、常時アクティブなプロキシオブジェクトへ付け替える
2. プロキシに `MA Mesh Cutter`(条件反転) + 全頂点選択の Vertex Filter を生成
3. MA がトグルをリアクティブ条件として拾い、NaNimation を生成する
4. メッシュは常時アクティブになるため、AAO の自動統合対象になる

レイヤー構造・パラメータ・メニューは一切変更しない。非破壊(ビルド時のみ)。
NaNimation の仕様上、変換1件ごとにボーンが数本増える(ポリゴン数は不変)。

## 依存

- VRChat SDK - Avatars 3.7 以上
- NDMF (`nadena.dev.ndmf`) 1.14 以上
- Modular Avatar (`nadena.dev.modular-avatar`) 1.18 以上
